# Reference catalog

This catalog distinguishes between:

- **Reusable open source/open content**: may be incorporated only under its stated license and with required notices.
- **Public reference only**: may be linked and consulted, but must not be copied into AxiomEmbedded  unless explicit reuse permission exists.
- **Restricted or licensed standard**: record only bibliographic metadata and permitted clause identifiers. Contributors must obtain authorized access separately.

The catalog is not legal advice and does not guarantee license compatibility. Always inspect the exact version and repository license before reuse.
