# diag-uds-testgen

Deterministic reference generator for the `automotive-diagnostics` skill (Rules 5–7).

Converts a canonical UDS test-spec (YAML/JSON, see `schemas/uds-test-spec.schema.json`)
— produced by adapters from DEXT/ARXML, ODX/PDX, CDD, XLS/XLSX, or OTX sequence oracles —
into a full per-service positive + negative test matrix plus validation outline,
traceability CSV, and provenance sidecar.

## Usage

```bash
python tools/diag-uds-testgen/generate_uds_tests.py \
  --spec tools/diag-uds-testgen/tests/minimal_spec.yaml \
  --out out/DoorECU --ecu DoorECU
python -m pytest tools/diag-uds-testgen/tests -q
```

Stdlib only. Same spec + same tool version yields byte-identical output.
Generated files carry `GENERATED BY ... DO NOT EDIT` headers; provenance (hashes,
versions) is isolated in `uds_provenance.json`.

Input/output contracts are schema-backed and deterministic.
