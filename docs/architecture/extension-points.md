# Extension points

A new domain, platform, tool or agent should be addable without modifying core lifecycle logic.

## Domain plugin

Declare domain metadata, applicable controls, checklists and profile hooks.

## Platform plugin

Declare architecture/SoC/OS/build/debug capabilities and tool hooks.

## Tool adapter

Declare deterministic command/adapter contracts, inputs, outputs, timeout behaviour and evidence hooks.

## Agent

Declare capabilities, inputs, outputs, context policy, permissions and evaluation cases.
