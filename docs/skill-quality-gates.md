# Skill Quality Gates

A skill is accepted only if ALL hold:

- [ ] Solves a real engineering workflow end to end (senior-engineer usable).
- [ ] Produces at least one concrete artifact (template/report/matrix).
- [ ] Validation steps defined AND executable (`validate_skills` PASS).
- [ ] Failure modes + remediation documented.
- [ ] MCP integration documented (existing or specified tool).
- [ ] No copied external text (original AxiomEmbedded content).
- [ ] Consistent naming/branding (`axiom-<domain>-<capability>`).
- [ ] Repo lint/CI green (YAML, Markdown, Python, catalog, links).
- [ ] Safety/security guidance gated (`review_required: true`).
- [ ] Maturity honest: production only with tests + docs + examples + acceptance.
