# Skills Contributing

- Original content only. Never copy prompts/examples/structure from external repos.
- Small composable change per PR; keep public contracts backward-compatible.
- New skill: scaffold + workflow + checklist + template + script + tests + catalog entry.
- Safety/security-relevant guidance always sets `review_required: true`.
- Run `python scripts/validate_skills.py` and `python -m pytest -q` before PR.
