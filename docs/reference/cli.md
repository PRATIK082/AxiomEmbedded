# CLI reference

| Command | Purpose |
|---|---|
| `axiom doctor` | Environment/repository smoke checks |
| `axiom repo validate` | Structural validation |
| `axiom analyze PATH` | Build a repository file index |
| `axiom graph build PATH` | Build/update index |
| `axiom context select` | Select bounded context roots |
| `axiom profile validate FILE` | Validate profile shape |
| `axiom workflow plan` | Determine lifecycle entry/start phase |
| `axiom impact FILE` | Inspect project entry/lifecycle baseline |
| `axiom route TEXT` | Route intent to a specialist agent |
