# Agent command reference

```bash
python -m axiom_cli doctor
python -m axiom_cli repo validate
python -m axiom_cli analyze .
python -m axiom_cli graph build .
python -m axiom_cli context select --root <path>
python -m axiom_cli workflow plan --profile <profile>
python -m axiom_cli route "<request>"
```

Use these commands to establish a bounded project state before using an AI coding agent.
