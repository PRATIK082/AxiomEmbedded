# Axiom Robot Acceptance Protocol Review

## Purpose
Independently reviews the acceptance protocol for robot acceptance protocol work. Defines the acceptance protocol: FAT/SAT stages, test criteria, performance sampling, and sign-off evidence.
This is the checklist reviewer partner of the builder skill; it never modifies the artifact, it records a verdict.

## When to Use
- The project needs the robot acceptance protocol review workflow.
- Inputs listed below are available.

## When Not to Use
- As a substitute for qualified safety/security certification review.
- When the required inputs are absent (record the gap instead of inventing data).

## Required Inputs
- contract requirements.
- cell design.
- safety functions.


## Review Workflow
1. Confirm the builder artifact exists and matches its template.
2. Apply each checklist gate; sample evidence, do not trust assertions.
3. Audit traceability links end to end.
4. Record verdict: pass, pass-with-findings, or fail, with severity-ranked findings.
5. Record reviewer independence and hand back open questions.
